<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

On Linux:
  ```sh
  sudo apt update
  sudo apt upgrade
  sudo apt install 
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/tharnyelilvannan/CharacterDriver.git
   ```
2. Change directory to project
   ```sh
   cd CharacterDriver
   ```
3. Change script file permissions
   ```sh
   sudo chmod 777 ./scripts/.
   ```
